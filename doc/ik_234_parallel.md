# 2、3、4 轴平行六轴机械臂逆运动学求解思路

## 1. 构型特点

J2、J3、J4 的旋转轴始终平行（均沿各自父坐标系的 Y 方向），构成一个**平面三连杆机构**。J5、J6 为腕部姿态关节，二者轴线正交，不交于一点。

与球腕构型（J4/J5/J6 交于一点，位置和姿态完全解耦）不同，本构型的核心难点在于：J2/J3/J4 既要满足腕部位置，又要贡献一部分末端朝向。

## 2. MDH 参数

| i | α_{i-1} | a_{i-1} | d_i | θ_i |
|---|---------|---------|-----|-----|
| 1 | 0 | 0 | L_BASE | θ_1 |
| 2 | -π/2 | D_BASE | 0 | θ_2 |
| 3 | 0 | L_UPPERARM | 0 | θ_3 |
| 4 | -π/2 | D_ELBOW | L_FOREARM | θ_4 |
| 5 | π/2 | 0 | 0 | θ_5 |
| 6 | -π/2 | 0 | L_WRIST | θ_6 |

## 3. 关节轴向分析

在 MDH（Craig 约定）下，关节 i 的旋转轴为 Z_{i-1}。Z_{i} 在其自身坐标系 {i} 下恒为 (0,0,1)^T，转换到父系 {i-1} 的表达式仅取决于 α_{i-1}：

$
Z_i^{(i-1)} = R_X(\alpha_{i-1}) \cdot \begin{bmatrix}0\\0\\1\end{bmatrix}
$

代入参数：

| 关节 | 自身轴方向 | 在父系的方向 |
|------|-----------|-------------|
| J1 | Z_0 | (0,0,1) 垂直 |
| J2 | Z_1 | (0,1,0) 水平 |
| J3 | Z_2 | (0,0,1) → 转到{1}系后恒为 (0,1,0)，**与 J2 平行** |
| J4 | Z_3 | (0,1,0) → 转到{2}系后恒为 (0,1,0)，**与 J2、J3 平行** |
| J5 | Z_4 | (0,-1,0) 与 J4 正交 |
| J6 | Z_5 | (0,1,0) 与 J5 正交 |

**关键性质**：J2、J3、J4 在 {1} 系下的轴向恒为 Y 方向，且旋转矩阵满足：

$
R_1^4 = R_Y(\theta_2) \cdot R_Y(\theta_3) \cdot R_Y(\theta_4) = R_Y(\theta_2 + \theta_3 + \theta_4)
$

**只有和角 Σ_{234} = θ_2+θ_3+θ_4 影响坐标系 {4} 的姿态，单个角度无法从姿态直接分离。**

## 4. 逆解步骤

### 4.1 已知条件

- 末端位姿：位置 P_06，姿态矩阵 R_06
- 上一周期的关节角（用于选解）
- 连杆参数：L_BASE, D_BASE, L_UPPERARM, D_ELBOW, L_FOREARM, L_WRIST

### 4.2 第一步：求解 J1

腕部参考点（坐标系 {4} 原点在基系下的位置）：

$
P_{04} = P_{06} - R_{06} \cdot L_{6\_wrist}
$

其中 L_{6\_wrist} = R_06 * [0, 0, -L_WRIST]^T 是末端到腕部的向量。

J1 绕基系 Z 轴旋转，P_{04} 在 XY 平面的投影决定 J1：

$
\theta_1^{(1)} = \text{atan2}(P_{04}.y,\ P_{04}.x)
$

$
\theta_1^{(2)} = \text{atan2}(-P_{04}.y,\ -P_{04}.x)
$

2 组解（肩左/肩右）。

**奇异情况**：若 P_{04}.x ≈ 0 且 P_{04}.y ≈ 0（腕部在 J1 轴线上），J1 有无穷解，沿用上一周期角度。

### 4.3 第二步：转换到 {1} 系

对于每一组 θ_1，计算旋转矩阵 R_01 = R_Z(θ_1)，将相关量转到 {1} 系：

$
P_{14} = R_{01}^T \cdot (P_{04} - P_{01})
$
$
R_{16} = R_{01}^T \cdot R_{06}
$

其中 P_{01} 是 {1} 系原点在基系的位置（即 L0_Base 经 J1 旋转后的结果）。

### 4.4 第三步：确定和角 Σ_{234}

{4} 系到 {6} 系的姿态由 J5、J6 决定：

$
R_4^6 = R_Y(\theta_5) \cdot R_Y(\theta_6) \quad \text{（实际按 MDH 参数为 } R_Z(\theta_5) \cdot R_X(\alpha_4) \cdot R_Z(\theta_6) \cdot R_X(\alpha_5) \text{）}
$

等价地，我们可以利用"J2/J3/J4 只贡献绕 Y 的旋转"这一性质：

R_{14} 必须是绕 Y 轴的纯旋转矩阵。从 R_{16} 中"扣除"腕部 J5/J6 应贡献的旋转后，剩余的就是 R_{14}。

**数值方法**：设腕部还未求解，但注意到 R_{14} = R_Y(Σ_{234}) 的结构意味着：

$
R_{14} = \begin{bmatrix}
\cos\Sigma & 0 & \sin\Sigma \\
0 & 1 & 0 \\
-\sin\Sigma & 0 & \cos\Sigma
\end{bmatrix}
$

而 R_{16} = R_{14} · R_{46}。若我们已知 {4} 系到 {6} 系的姿态仅由 J5 绕特定轴贡献，可以从中提取 Σ。

**实际操作中**，可以先假设一个合理的 θ_5（或沿用上周期值），求出 R_{46}，进而：

$
R_{14} = R_{16} \cdot R_{46}^T
$

从 R_{14} 提取 Σ_{234} = atan2(R_{14}(0,2), R_{14}(0,0))。

### 4.5 第四步：求解 J2、J3、J4（平面 3R 问题）

在 {1} 系的 X-Z 平面内（J2/J3/J4 均绕 Y 轴，平面运动发生在 X-Z 平面）建立几何关系。

**已知量**：
- {1} 系原点 O_{1}
- {4} 系原点在 {1} 系的位置 P_{14}
- {4} 系的朝向角 Σ_{234}（绕 Y 轴）
- 连杆参数在 X-Z 平面内的投影长度

**几何构造**：

坐标系 {3} 的原点相对于 {4} 系原点的偏移在 {1} 系下为：

$
\vec{O_3O_4}^{(1)} = -R_Y(\Sigma_{234}) \cdot \begin{bmatrix} a_3 \\ 0 \\ d_4 \end{bmatrix}
$

其中 a_3 = D_ELBOW, d_4 = L_FOREARM。

于是 {3} 系原点在 {1} 系的位置：

$
P_{13} = P_{14} + \vec{O_3O_4}^{(1)}
$

现在 P_{13} 已知，问题退化为 **J2 + J3 的平面 2R 子问题**：

- 连杆 2 长度：a_2 = L_UPPERARM
- 连杆 3 在 X-Z 平面的等效长度：√(a_3² + d_4²)（实际这里注意：连杆 3 连接 {2} 到 {3}，{2} 原点到 {3} 原点的向量在 {2} 系下由 MDH 参数决定）

**2R 子问题求解**（余弦定理）：

{1} 系原点到 {3} 系原点的距离在 X-Z 平面投影为 d = √(P_{13}.x² + P_{13}.z²)。

记 O_1 到 O_2 在 X-Z 平面的等效长度为 l_2，O_2 到 O_3 在 X-Z 平面的等效长度为 l_3（由 MDH 参数 a_1, a_2, d_2, d_3 确定）。

由余弦定理：

$
\cos(\pi - \theta_3) = \frac{l_2^2 + l_3^2 - d^2}{2 \cdot l_2 \cdot l_3}
$

得到 θ_3 的两组解（肘上/肘下），进而由 P_{13} 的方向反求 θ_2。

最后：

$
\theta_4 = \Sigma_{234} - \theta_2 - \theta_3
$

### 4.6 第五步：求解 J5、J6（腕部姿态）

J1~J4 全部确定后，{4} 系姿态 R_{04} 已知。剩余姿态：

$
R_{46} = R_{04}^T \cdot R_{06}
$

J5 由 R_{46} 的特定元素解析：

$
\theta_5 = \text{atan2}\left(\pm\sqrt{R_{46}(0,2)^2 + R_{46}(2,2)^2},\ R_{46}(1,2)\right)
$

（具体符号取决于 MDH 参数列，本质是腕部两个翻转解。）

**奇异情况**：当 θ_5 ≈ 0 或 θ_5 ≈ π 时，J5 和 J6 轴线共线，产生万向节锁。此时 θ_4 和 θ_6 有无穷多组解，需沿用一个上一周期的值，反求另一个。

$
\theta_6 = \text{atan2}\left(\mp R_{46}(1,0),\ \pm R_{46}(1,1)\right)
$

### 4.7 第六步：选解

- J1：2 组（肩左/右）
- J3：2 组（肘上/下）
- J5：2 组（腕翻/不翻）

共 8 组解。选择与上一周期关节角最接近（加权欧氏距离最小）的一组作为最终输出。

## 5. 与球腕构型的核心区别

| 对比维度 | 球腕构型 | 234 平行构型 |
|---------|---------|------------|
| 腕部结构 | J4/J5/J6 交于一点 | J5/J6 不交于一点 |
| 位置解耦 | J1+(J2,J3) 两步独立求解 | J1 独立，但 J2/J3/J4 需含朝向约束联合求解 |
| 朝向处理 | J4/J5/J6 从 R_{36} 直接解析 | 先提取 Σ_{234} 和角，分离出 R_{46} 再求 J5/J6 |
| 核心几何 | 空间三角（余弦定理） | 平面 3R 末端已知位姿（退化为 2R + 和角约束） |
| 冗余 | 无 | J2/J3/J4 共 3 个关节共享 1 个朝向自由度 |

## 6. 特殊/奇异位形处理

1. **腕部在 J1 轴线上**（P_{04} 的 X、Y 分量均接近 0）：J1 无穷解，沿用上周期值，solveFlag 标记为 -1
2. **肘部奇异**（目标点刚好在连杆极限距离上）：θ_3 = 0 或 π，标记 solveFlag
3. **腕部奇异**（θ_5 ≈ 0 或 π，J4 和 J6 共线）：无法通过 atan2 分离 θ_4 和 θ_6，沿用一个上周期值求解另一个，solveFlag 标记为 -1
